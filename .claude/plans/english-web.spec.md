# โปรเจกต์: เว็บสอนภาษาอังกฤษแบบเจ้าของภาษา สำหรับคนไทย

> สเปกต้นฉบับจากผู้ใช้ (2026-11-13) — ใช้คู่กับแผนใน [english-web.plan.md](english-web.plan.md)

## แนวคิดหลัก
สอนภาษาอังกฤษแบบที่เด็กเจ้าของภาษาเรียนจริง ตั้งแต่แรกเกิดฟังพ่อแม่พูด → พูดตาม
→ สื่อสารในชีวิตประจำวัน → เข้าโรงเรียนอ่านและเขียนได้
ลำดับบังคับ: ฟัง → พูด → อ่าน → เขียน
เน้นเรียนจากภาพ + เสียง + บริบทจริง และเรียนเป็นวลี (chunks) ไม่เน้นท่องไวยากรณ์
ใช้ภาษาที่เจ้าของภาษาพูดจริงในชีวิตประจำวัน ไม่ใช่ภาษาแบบเรียน
ทำให้สนุกเหมือนเล่นเกม เพื่อให้ผู้ใช้กลับมาเรียนทุกวัน และพูดได้จริงในระยะยาว

## เทคโนโลยี
- React + Vite (JavaScript ไม่ใช้ TypeScript)
- React Router สำหรับเปลี่ยนหน้า
- จัดการ state ส่วนกลาง (XP, เลเวล, streak, การปลดล็อก, ตั้งค่า) ด้วย Zustand
  พร้อม persist ลง localStorage อัตโนมัติ
- สไตล์: CSS Modules (ไฟล์ .module.css คู่กับแต่ละ component)
- Responsive รองรับมือถือเป็นหลัก (mobile-first)
- เสียงพูด: Web Speech API (speechSynthesis) สำเนียง en-US
- รับเสียง: SpeechRecognition (lang: en-US)
  ถ้าเบราว์เซอร์ไม่รองรับ แสดงข้อความแจ้งว่าให้ใช้ Chrome หรือ Edge
- อัดเสียงผู้ใช้: MediaRecorder API
- เก็บไฟล์เสียงใน IndexedDB
- รันด้วย npm run dev (เป็น localhost ไมค์จึงใช้งานได้)

## ภาษาของหน้าเว็บ (UI) สลับ ไทย / อังกฤษ
- ปุ่มสลับภาษา "TH | EN" อยู่มุมบนขวาทุกหน้า และอยู่ในหน้าตั้งค่า
- ค่าเริ่มต้น: ไทย, จำค่าที่เลือกไว้ใน localStorage
- ใช้ react-i18next แยกข้อความ UI ไว้ใน src/locales/th.json และ src/locales/en.json
  ห้ามเขียนข้อความ UI ตรง ๆ ใน component ทุกข้อความต้องผ่าน t('key')
- ภาษา UI เปลี่ยนเฉพาะ: เมนู, ปุ่ม, หัวข้อ, คำสั่งกิจกรรม, ข้อความให้กำลังใจ, ข้อความแจ้งเตือน
- ภาษา UI ไม่เปลี่ยน: เนื้อหาบทเรียนภาษาอังกฤษ, คำแปลไทย, คำอ่านไทย
  (คำแปล/คำอ่านไทยเปิด-ปิดแยกในตั้งค่า ตามส่วนที่ 10.2)
- โหมด UI อังกฤษเป็นทางเลือกให้ผู้เรียนที่อยากฝึกอยู่กับภาษาอังกฤษล้วน
  ให้ใช้ภาษาอังกฤษง่าย ๆ สั้น ๆ ในไฟล์ en.json

## ส่วนที่ 1: หลักการเขียนเนื้อหา (ใช้กับเนื้อหาทุกส่วนในเว็บ)
- เขียนแบบที่เจ้าของภาษาพูดจริง ไม่ใช่ภาษาแบบเรียน
  ❌ "How are you?" "I am fine, thank you. And you?"
  ✅ "Hey, how's it going?" "Not bad, you?"
- ใช้รูปย่อเสมอ: I'm, don't, gonna, wanna, gotta, y'know
- มีคำเติมและคำตอบรับแบบธรรมชาติ: um, like, actually, oh nice, no way, fair enough,
  sounds good, my bad, no worries, I mean
- เน้น phrasal verbs และ collocations ที่ใช้บ่อย:
  pick up, hang out, run out of, figure out, grab a coffee, make it, catch up
- ทุกคำ/วลีระบุ register: casual / neutral / formal
  และ frequency: ใช้บ่อยมาก / ใช้บ่อย / ใช้บางครั้ง
- สแลงใช้ได้แต่ต้องเป็นสแลงที่ใช้กันทั่วไป ไม่หยาบ และมีหมายเหตุภาษาไทยว่าใช้กับใครได้
- Stage 1–4 ใช้ภาษาแบบพ่อแม่คุยกับลูก (parentese): ช้า ชัด ซ้ำ ใช้คำเดิมในหลายประโยค

## ส่วนที่ 2: องค์ประกอบพื้นฐาน (ใช้ซ้ำทุก Stage)

### 2.1 การ์ดคำศัพท์
- ภาพประกอบ
- คำภาษาอังกฤษใต้ภาพ (ซ่อน/แสดงตาม Stage)
- ความหมายภาษาไทย (ซ่อนไว้ กดดูได้)
- คำอ่านภาษาไทย เช่น "apple" → "แอ๊ป-เพิ่ล" ระบุพยางค์ที่ลงเสียงหนัก (เปิด/ปิดได้)
- ปุ่ม 🔊 ฟังเสียง มีตัวเลือกความเร็ว ปกติ / ช้า
- ปุ่ม 🎤 พูดตาม → เทียบกับคำเป้าหมาย แสดง ✅ ถูก / 🔁 ลองอีกครั้ง
  และแสดงคำที่ระบบได้ยิน

### 2.2 ประโยคในบริบท
- ภาพฉากสถานการณ์
- ประโยคยาวแบบที่เจ้าของภาษาพูดจริง 1–3 ประโยค + คำแปลไทย + คำอ่านไทย
- ไฮไลต์คำสำคัญในประโยค คลิกแล้วแสดง "คำที่ใช้แทนได้ในบริบทนี้" 3–5 คำ
  แต่ละคำมี: ความหมาย, register, ปุ่มฟังเสียง
  คลิกคำแนะนำ → สลับเข้าไปในประโยคทันที ให้เห็นประโยคใหม่
- ปุ่ม 🔊 อ่านทั้งประโยค และ 🎤 พูดตามทั้งประโยค
  แสดงเปอร์เซ็นต์ความถูกต้อง และคำที่พูดไม่ตรงเป็นสีแดง

### 2.3 การพูดแบบเจ้าของภาษาจริง (แสดงในประโยคบริบทและบทสนทนา)
- connectedSpeech: เสียงที่พูดเชื่อมกันจริง เช่น
  "want to" → "wanna", "going to" → "gonna", "did you" → "ดิด-จู"
  แสดงป้าย "เจ้าของภาษาพูดว่า..." พร้อมคำอ่านไทย
- stress: ไฮไลต์คำที่ลงเสียงหนัก
- intonation: ลูกศร ↗ / ↘ ท้ายประโยค
- casual vs formal: ถ้ามี แสดงทั้งสองแบบ

### 2.4 การตอบกลับแบบพ่อแม่ (Recast)
เมื่อผู้ใช้พูดไม่ถูก ห้ามขึ้นว่า "ผิด" ให้ระบบทวนประโยคที่ถูกต้องกลับมาอย่างเป็นธรรมชาติ
เช่น ผู้ใช้พูด "he go school" → ระบบพูด "Yes! He goes to school." แล้วให้ลองพูดอีกครั้ง
(ใช้รูปแบบผิดที่พบบ่อยซึ่งกำหนดไว้ใน lessons.json ถ้าไม่ตรงรูปแบบไหน ให้ทวนประโยคเป้าหมาย)

## ส่วนที่ 3: เส้นทางเรียนพื้นฐาน 7 Stage (ตามพัฒนาการเด็กเจ้าของภาษา)
ปลดล็อกทีละ Stage เมื่อผ่านบทเรียนครบ และการผ่าน Stage ใช้ปลดล็อกสถานที่ในแผนที่เมือง (ส่วนที่ 7)

### Stage 1 ช่วงฟัง (ทารก 0–12 เดือน)
- ฟังอย่างเดียว ไม่บังคับพูด ไม่แสดงตัวอักษร
- ภาพ + เสียงแบบ parentese เช่น "Look! A dog. The dog is big. Big dog!"
- กิจกรรม: ฟังเสียงแล้วแตะภาพให้ถูก

### Stage 2 คำเดี่ยว (1 ขวบ)
- คำพื้นฐาน: mama, milk, ball, dog, more, no, up, bye
- ภาพ → พูดคำเดียวผ่านไมค์ ตรวจแบบผ่อนปรน
- ยังไม่แสดงตัวอักษร

### Stage 3 สองคำ (1.5–2 ขวบ)
- "more milk", "big dog", "daddy go", "no sleep"
- ภาพแสดงการกระทำ → พูดคำคู่ให้ตรงภาพ
- ยังไม่แสดงตัวอักษร

### Stage 4 ประโยคสั้น (2–3 ขวบ)
- "I want juice.", "Where is the cat?", "I don't like it."
- เริ่มมีคำถาม-ตอบ และใช้ Recast (2.4)
- แสดงข้อความได้แบบกดเปิดดู (ค่าเริ่มต้นซ่อน)

### Stage 5 สนทนาชีวิตประจำวัน (3–5 ขวบ)
- ใช้ประโยคในบริบท (2.2) และการพูดแบบเจ้าของภาษา (2.3)
- บทสนทนา 4–6 บรรทัด: กินข้าว อาบน้ำ เล่น ไปร้านค้า
  ผู้ใช้เลือกเป็นตัวละครหนึ่ง ระบบพูดบทอีกฝ่าย แล้วรอผู้ใช้พูดผ่านไมค์
- เล่าเรื่องจากภาพ 3–4 ภาพต่อกัน (picture story) ด้วยการพูด
  ตรวจว่ามีคำ/วลีสำคัญที่กำหนดไว้หรือไม่
- เพลง/นิทานคล้องจองที่แต่งขึ้นเอง ฝึกจังหวะและเสียงท้ายคำ

### Stage 6 เข้าโรงเรียน: อ่าน (5–6 ขวบ)
- Phonics ตัวอักษร → เสียง
- ผสมเสียงเป็นคำ (c-a-t → cat) โดยใช้คำที่เคยพูดได้แล้วใน Stage 1–5
- Sight words (the, is, you, and, said)
- อ่านนิทานสั้นออกเสียงผ่านไมค์ ไฮไลต์คำที่กำลังอ่าน

### Stage 7 เขียน (6–8 ขวบ)
ลำดับจากง่ายไปยาก:
1. ฟังคำแล้วพิมพ์ (dictation)
2. เติมคำในประโยค
3. เรียงคำเป็นประโยค (ลากวาง)
4. เขียนประโยคบรรยายภาพเอง
5. เขียนเรื่องสั้น 3–5 ประโยคจากภาพ
ตรวจตัวสะกด และแสดงประโยคตัวอย่างที่ถูกต้องให้เทียบ

## ส่วนที่ 4: ลำดับขั้นภายในแต่ละบทเรียน (Stage 4 ขึ้นไป)
1. ดูภาพ + ฟังเสียง (ยังไม่โชว์ข้อความ) ให้เดาความหมายจากภาพ
2. โชว์ข้อความ (+ คำแปล/คำอ่านไทย ถ้าผู้ใช้เปิด)
3. ฟังแบบช้า → ฟังแบบปกติ
4. Shadowing: พูดตามทันทีผ่านไมค์ ให้คะแนนรายคำ
5. สลับคำในบริบท
6. ใช้เอง: ปิดข้อความ ดูแค่ภาพแล้วพูดเอง
7. สรุปท้ายบท: คำที่ถูก/ไม่ถูก + ปุ่มฝึกซ้ำเฉพาะคำที่พลาด
(Stage 1–3 ใช้แค่ขั้น 1, 3, 4 และไม่แสดงข้อความ)

## ส่วนที่ 5: คลังคำศัพท์และวลีใช้งานจริง
- จัดกลุ่มตามสถานการณ์ ไม่ใช่ตามหมวดแบบเรียน เช่น
  "ทักทาย/บอกลา", "สั่งอาหาร", "ขอให้ช่วย", "ปฏิเสธอย่างสุภาพ", "แสดงความรู้สึก",
  "ชวนเพื่อน", "ขอโทษ", "ต่อรอง/ซื้อของ", "ถามทาง", "ที่ทำงาน", "โทรศัพท์/แชท"
- แต่ละคำ/วลีมี: ความหมายไทย, คำอ่านไทย, ประโยคตัวอย่างจริง 2 ประโยค,
  register, frequency, และ "คนไทยมักพูดผิดว่า..." (ถ้ามี)
  เช่น ❌ "open the light" → ✅ "turn on the light"
- หน้า "คำในตำรา vs คำที่เจ้าของภาษาใช้จริง" เช่น
  "I don't understand" → "Sorry, I didn't catch that" / "Come again?"
  "Very good" → "Awesome" / "That's great"

## ส่วนที่ 6: บทสนทนาสุ่มแบบชีวิตจริง (Random Conversation)
ไม่มี AI ให้ใช้ระบบ template + สุ่ม เพื่อให้แต่ละรอบไม่เหมือนกัน:
- scenarios: ร้านกาแฟ, ร้านสะดวกซื้อ, เรียกรถ, เจอเพื่อนเก่า, สัมภาษณ์งาน,
  เช็คอินโรงแรม, ร้านอาหาร, ถามทาง, คุยกับเพื่อนร่วมงาน, นัดเพื่อน
- บทพูดของอีกฝ่ายแต่ละ turn มี 3–5 แบบ (variants) สุ่มเลือกทุกครั้ง
  เช่น พนักงานทัก: "What can I get you?" / "Hi, what'll it be?" / "Ready to order?"
- ช่องสุ่มค่า (slots): ชื่อเมนู, ราคา, เวลา, สถานที่, ชื่อคน
  เช่น "That'll be {price}." → สุ่ม $4.50 / $6.25
- เหตุการณ์สุ่ม (twist) 30% ของรอบ เช่น ของหมด, ได้ของผิด, ร้านจะปิดแล้ว, รถติด
  ผู้ใช้ต้องรับมือด้วยประโยคที่เหมาะสม
- ฝั่งผู้ใช้: แสดงตัวเลือกคำตอบ 2–3 แบบ (casual/neutral/formal) ให้เลือกแล้วพูดผ่านไมค์
  ระดับยาก: ซ่อนตัวเลือก ให้แค่คำใบ้ภาษาไทย เช่น "(ขอเปลี่ยนเป็นนมโอ๊ต)"
  ตรวจว่ามีคำสำคัญ (requiredWords) อยู่ในสิ่งที่พูด และยอมรับได้หลายแบบ (acceptedAnswers)
- ปุ่ม "สุ่มสถานการณ์ใหม่" และ "สุ่มอีกรอบ (สถานการณ์เดิม)"
- จบบทแสดงทั้งบทสนทนา + วลีใหม่ที่เจอ + ปุ่มเพิ่มเข้ารายการทบทวน

## ส่วนที่ 7: โหมดเรื่องราว "ชีวิตใหม่ในเมืองภาษาอังกฤษ"
- ผู้ใช้เป็นตัวละครที่เพิ่งย้ายไปอยู่เมืองที่พูดภาษาอังกฤษ
  ต้องใช้ชีวิตจริง: หาที่พัก ซื้อของ หาเพื่อน หางาน ไปเที่ยว
- หน้าแรกเป็น "แผนที่เมือง" ที่ปลดล็อกสถานที่ทีละที่
  บ้าน → ร้านสะดวกซื้อ → ร้านกาแฟ → สวนสาธารณะ → ร้านอาหาร → ออฟฟิศ → สนามบิน
- แต่ละสถานที่ผูกกับ Stage, คลังวลี (ส่วนที่ 5) และบทสนทนาสุ่ม (ส่วนที่ 6) ของสถานการณ์นั้น
- NPC ประจำเมือง 4–6 ตัว แต่ละตัวมีนิสัยและสไตล์การพูดต่างกัน
  (เช่น บาริสต้าพูดเร็วใช้สแลง, คุณป้าข้างบ้านพูดช้าสุภาพ, เพื่อนร่วมงานพูดแบบทางการ)
  ความสนิทกับ NPC เพิ่มขึ้นเมื่อคุยกันบ่อย → ปลดล็อกบทสนทนาที่ลึกขึ้น
- เส้นทาง 7 Stage เป็นโหมด "เรียนพื้นฐาน" ที่ต้องผ่านเพื่อปลดล็อกสถานที่

## ส่วนที่ 8: ระบบเกมและแรงจูงใจ

### 8.1 รางวัล
- XP ได้จากทุกกิจกรรม และได้มากที่สุดจากการพูด
  (ฟัง 5 XP, พูดตาม 15 XP, พูดเองไม่ดูข้อความ 25 XP)
- เลเวลผู้เล่น + ฉายา: "Newcomer" → "Local" → "Smooth Talker" → "Native-ish"
- Streak เรียนต่อเนื่องรายวัน มี "Streak Freeze" 1 ครั้ง/สัปดาห์
- สมุดสะสม (Collection): สะสมวลีที่พูดผ่านแล้วเหมือนการ์ด
  วลีหายาก (สแลง, idiom) เป็นการ์ดระดับพิเศษ
- ตกแต่งห้องของตัวละครด้วยของที่ปลดล็อกจากเลเวล
- ห้ามใช้ระบบ "หัวใจหมดแล้วเล่นไม่ได้" พูดผิดได้ไม่จำกัด เพื่อให้กล้าพูด

### 8.2 มินิเกม (สลับกับบทเรียนเพื่อไม่ให้เบื่อ)
- Listen & Tap: ฟังแล้วแตะภาพให้ถูกภายในเวลาที่กำหนด
- Shadow Karaoke: ประโยควิ่งแบบคาราโอเกะ พูดให้ทันจังหวะ ได้คะแนนตามความตรง
- Word Swap Race: สลับคำในประโยคบริบทให้ได้มากที่สุดใน 60 วินาที
- Real or Textbook?: เลือกว่าประโยคไหนเจ้าของภาษาพูดจริง
- Minimal Pair Duel: ฟังคู่คำเสียงคล้าย (think/sink) เลือกให้ถูก
- Speed Order: บทสนทนาสุ่มแบบจับเวลา ตอบให้ทันก่อนพนักงานรอนาน

### 8.3 ภารกิจ
- รายวัน 3 ข้อ (สุ่ม) เช่น "พูดประโยคผ่าน 10 ประโยค", "คุยกับ NPC 1 คน", "เล่นมินิเกม 1 เกม"
- รายสัปดาห์: Boss Conversation = บทสนทนาสุ่มยาว มี twist 2 ครั้ง ไม่มีตัวเลือกคำตอบ
- นอกเว็บ (ติ๊กเองว่าทำแล้ว): "ดูคลิปภาษาอังกฤษ 15 นาที",
  "พูดบรรยายสิ่งที่ทำอยู่เป็นภาษาอังกฤษ 5 นาที", "เปลี่ยนภาษาโทรศัพท์เป็นอังกฤษ 1 วัน"

### 8.4 แผนรายวัน (วันละน้อยแต่สม่ำเสมอ)
- ผู้ใช้เลือกเป้าหมาย 5 / 10 / 15 / 20 นาทีต่อวัน
- ระบบจัดชุดกิจกรรมให้อัตโนมัติ:
  ทบทวน → บทเรียนใหม่ → บทสนทนาสุ่ม → มินิเกม 1 เกม
- ตัวนับ "นาทีที่พูดภาษาอังกฤษ" สะสม แสดงเป็นกราฟรายสัปดาห์

### 8.5 ทบทวนอัตโนมัติ (Spaced Repetition)
- รายการที่พลาดกลับมาทบทวนตามรอบ 1 → 3 → 7 → 14 วัน
- หน้าแรกมีปุ่ม "ทบทวนวันนี้ (X รายการ)"

### 8.6 ความรู้สึกระหว่างเล่น
- เสียงเอฟเฟกต์และแอนิเมชันเล็ก ๆ เมื่อพูดผ่าน ขึ้นเลเวล ปลดล็อกสถานที่ (ปิดได้)
- ข้อความให้กำลังใจภาษาไทยแบบเป็นกันเอง ไม่ตำหนิ
- หายไปหลายวัน กลับมาเจอ NPC ทักว่า "Hey! Long time no see!" พร้อมบททบทวนสั้น ๆ

## ส่วนที่ 9: วัดผลว่าพูดได้จริง (Speaking Check)
- ทุก 30 วัน ดูภาพชุดเดิม แล้วพูดบรรยาย 1 นาที อัดเสียงด้วย MediaRecorder
- เก็บไฟล์เสียงใน IndexedDB เปิดฟังเทียบวันที่ 1 กับวันนี้ได้
- สถิติประกอบ (คำนวณจากข้อความที่ถอดเสียงได้): คำต่อนาที, จำนวนวลีที่ใช้, จำนวนการหยุดนาน
- Milestone:
  30 วัน: แนะนำตัว + สั่งอาหาร + ถามทางได้
  90 วัน: คุยเรื่องชีวิตประจำวันได้ 3–5 นาที
  180 วัน: เล่าเรื่อง แสดงความเห็น และรับมือสถานการณ์ไม่คาดคิดได้

## ส่วนที่ 10: โหมดเสริมและตั้งค่า

### 10.1 โหมดฝึกเสียง (แยกจากเส้นทางหลัก เปิดได้ทุกเมื่อ)
- เสียงที่คนไทยออกยาก: th, r/l, v/w, sh/ch, z, เสียงท้ายคำ s/t/d/k
- คู่คำเสียงคล้าย (minimal pairs) เช่น think/sink, light/right, very/wery
- ฟังแล้วเลือกว่าได้ยินคำไหน + คำแนะนำตำแหน่งปาก/ลิ้นเป็นภาษาไทย

### 10.2 ตั้งค่า
- เปิด/ปิด คำอ่านไทย (ค่าเริ่มต้น: ปิดใน Stage 1–5)
- เปิด/ปิด คำแปลไทย (ค่าเริ่มต้น: ซ่อน กดดูได้)
- ภาษาของหน้าเว็บ: ไทย / อังกฤษ
- ความเร็วเสียงเริ่มต้น, เป้าหมายรายวัน, เปิด/ปิดเสียงเอฟเฟกต์
- รีเซ็ตความคืบหน้า

## ส่วนที่ 13: เนื้อหาตัวอย่าง
ใส่ข้อมูลตัวอย่างพอทดสอบทุกฟีเจอร์ โดยยึดหลักการในส่วนที่ 1:
- Stage 1–4: หมวด "บ้านและครอบครัว" อย่างละ 1 บท (บทละ 5 รายการ)
- Stage 5: บทสนทนา "ร้านกาแฟ" 1 บท + picture story 1 เรื่อง + ประโยคบริบท 2 ประโยค
- Stage 6: phonics 1 บท + นิทานสั้น 1 เรื่อง
- Stage 7: แบบฝึกเขียน 1 บท ครบ 5 ประเภท
- คลังวลี: 6 สถานการณ์ สถานการณ์ละ 8 วลี
- textbookVsReal: 15 คู่
- บทสนทนาสุ่ม: 5 scenarios (ร้านกาแฟ, ร้านสะดวกซื้อ, เจอเพื่อนเก่า, ถามทาง, เช็คอินโรงแรม)
  อย่างน้อย 6 turns, turn ของอีกฝ่ายมี 3 variants, และ 2 twists ต่อ scenario
- แผนที่เมือง: 7 สถานที่, NPC 4 ตัว
- ภารกิจรายวัน 15 แบบ
- โหมดฝึกเสียง: 3 เสียง (th, r/l, v/w)

## ส่วนที่ 14: ลำดับการทำ
ทำทีละขั้น และหยุดรอให้ผมทดสอบก่อนไปขั้นถัดไปทุกครั้ง
แต่ละขั้นให้สรุปสั้น ๆ ว่าทำอะไรไป ไฟล์ไหนเปลี่ยน และต้องทดสอบอะไร

   + โครงสร้างโฟลเดอร์ + ปุ่มสลับภาษา TH/EN + lessons.json (เริ่มจาก Stage 1–4)
   + การนำทางหน้าจอเปล่า ๆ
2. speech.js: ฟังเสียง (ปกติ/ช้า) + การ์ดคำศัพท์
3. ไมค์พูดตาม + เทียบคำ + ให้คะแนนรายคำ
4. Stage 1–3
5. Stage 4 + ระบบ Recast
6. ประโยคในบริบท + สลับคำ + connected speech/stress/intonation
7. Stage 5: บทสนทนา + picture story
8. Stage 6: phonics + อ่านนิทาน
9. Stage 7: แบบฝึกเขียน

ช่วง B: ภาษาชีวิตจริง
10. คลังวลีใช้งานจริง + หน้าคำในตำรา vs คำที่ใช้จริง
11. ระบบบทสนทนาสุ่ม (variants + slots)
12. twists + ระดับยาก (ซ่อนตัวเลือก)

ช่วง C: ทำให้สนุกและเรียนต่อเนื่อง
