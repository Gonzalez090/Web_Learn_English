# เมืองภาษาอังกฤษ (English Town)

เว็บเรียนภาษาอังกฤษแบบเจ้าของภาษา สำหรับคนไทย
เรียนตามลำดับที่เด็กเจ้าของภาษาเรียนจริง: **ฟัง → พูด → อ่าน → เขียน**
เน้นภาพ + เสียง + บริบทจริง และภาษาที่เจ้าของภาษาพูดจริงในชีวิตประจำวัน

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด <http://localhost:5173> ด้วย **Chrome หรือ Edge** (ระบบรับเสียงพูดใช้ได้เฉพาะ 2 เบราว์เซอร์นี้)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเว็บสำหรับพัฒนาที่ localhost (ไมค์ใช้ได้) |
| `npm run dev:phone` | เปิดแบบ https ให้มือถือในวง Wi-Fi เดียวกันเข้าได้ที่ `https://<IP เครื่อง>:5173` — ครั้งแรกต้องกดยอมรับใบรับรอง |
| `npm run build` | build เว็บจริงไว้ที่ `dist/` |
| `npm run lint` | ตรวจโค้ด + ตรวจว่าไม่มีข้อความ UI เขียนตรง ๆ ใน JSX (ต้องผ่าน `t('key')`) |
| `npm test` | unit test: ข้อมูลบทเรียน, ไฟล์ภาษา th/en, ไฟล์ภาพ/เสียงครบ, ฟังก์ชันใน `utils/` |
| `npm run audio` | สร้างไฟล์เสียงเจ้าของภาษาด้วย Kokoro (AI โอเพนซอร์ส ฟรี) ให้ทุกข้อความในบทเรียน — **รันทุกครั้งที่เพิ่ม/แก้เนื้อหา** (ครั้งแรกดาวน์โหลดโมเดลราว 90MB) |

### เสียงพูด

- คำ/ประโยคในบทเรียนใช้ **ไฟล์เสียงที่สร้างไว้ล่วงหน้า** (`public/audio/*.mp3`, สารบัญ `src/data/audioManifest.json`)
  → ทุกเครื่องได้ยินเสียงเดียวกัน ใช้ได้แม้ไม่มีเน็ต
- ข้อความที่ยังไม่มีไฟล์ → ใช้เสียงของเบราว์เซอร์ (เลือกได้ในหน้าตั้งค่า) → ถ้าเสียงออนไลน์ใช้ไม่ได้ สลับเป็นเสียงในเครื่องเอง
- `npm test` จะไม่ผ่านถ้ามีข้อความในบทเรียนที่ยังไม่มีไฟล์เสียง

## โครงสร้างโฟลเดอร์

```
src/
  main.jsx, App.jsx      จุดเริ่มต้น + เส้นทาง (routes)
  i18n.js                ตั้งค่าภาษาหน้าเว็บ TH/EN
  locales/               ข้อความ UI: th.json, en.json (key ต้องตรงกัน)
  pages/                 หน้าหลักแต่ละหน้า
  components/            component ที่ใช้ซ้ำ (+ .module.css คู่กัน)
    layout/              แถบบน, แถบเมนูล่าง
    games/               มินิเกม
  hooks/                 useSpeech, useRecognition, useRecorder, ...
  store/                 Zustand: settings, progress, review (บันทึกลง localStorage)
  utils/                 ฟังก์ชันคำนวณล้วน ๆ (มี test)
  data/                  เนื้อหาบทเรียน (lessons, phrases, scenarios, world, game)
  styles/global.css      ตัวแปรสี/ระยะ/ฟอนต์ + reset
public/images/           ภาพถ่ายประกอบ (WebP 640px จาก Pixabay — เครดิตใน src/data/imageCredits.json)
scripts/                 สคริปต์รันในเครื่อง (ดึงภาพจาก Pixabay) — ไม่ติดไปในเว็บ
```

## ความปลอดภัย

สิ่งที่ทำไว้แล้ว (ตรวจได้จากไฟล์ใน `dist/` หลัง `npm run build`):

- **ไม่มี source map** — คนเปิด F12 เห็นแค่โค้ดที่ย่อแล้ว ไม่เห็นโค้ดต้นฉบับและคอมเมนต์
- **ไม่มี API key ในเว็บ** — `PIXABAY_API_KEY` อยู่ใน `.env.local` (git ไม่เก็บ) ใช้แค่สคริปต์ในเครื่อง
  และ Vite ส่งเข้าเว็บเฉพาะตัวแปรที่ขึ้นต้นด้วย `VITE_` เท่านั้น → **ห้ามตั้งชื่อ key ลับขึ้นต้นด้วย `VITE_`**
- **เครื่องมือนักพัฒนาไม่ติดไปเว็บจริง** — หน้า `/dev`, ข้อความของหน้า dev (`src/locales/dev.*.json`),
  ฟังก์ชัน `devUnlockAll` มีเฉพาะตอน `npm run dev`
- **Content-Security-Policy** (ใส่ตอน build) — โหลดสคริปต์/สไตล์/ฟอนต์/ภาพจากเว็บเราเองเท่านั้น
- **ไม่โหลดอะไรจากเว็บอื่น** — ฟอนต์เก็บไว้ในเว็บเอง (`@fontsource`) ไม่ส่งข้อมูลผู้ใช้ไปที่ Google Fonts
- **หน้าพังไม่โชว์รายละเอียด error** — `ErrorBoundary` แสดงข้อความเป็นมิตรแทน (รายละเอียดโชว์เฉพาะตอน dev)
- **กฎ lint** — ห้าม `console.*`, `debugger`, `alert`, `eval`, `dangerouslySetInnerHTML` ในโค้ดเว็บ

ตอนเอาขึ้นโฮสต์จริง ให้ตั้ง HTTP header เหล่านี้ที่โฮสต์ด้วย (`npm run preview` ใส่ให้แล้วไว้ลองดู):
`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`,
`Referrer-Policy: strict-origin-when-cross-origin`,
`Permissions-Policy: microphone=(self), camera=(), geolocation=(), payment=()`

สิ่งที่ซ่อนไม่ได้ (เป็นธรรมชาติของเว็บที่ไม่มีเซิร์ฟเวอร์):

- เนื้อหาบทเรียน (รวมคำตอบ) ต้องส่งไปที่เบราว์เซอร์จึงจะแสดงผลได้ คนเปิด F12 จึงหาเจอได้
- ความคืบหน้า (XP, streak) อยู่ใน localStorage ของผู้ใช้เอง ผู้ใช้แก้เองได้ — ไม่กระทบใครเพราะไม่มีระบบแข่งกัน
  ถ้าวันหลังทำตารางอันดับ ต้องมีเซิร์ฟเวอร์ตรวจคะแนนแทน
- ตอน `npm run dev` เห็นโค้ดทุกอย่างเป็นเรื่องปกติของการพัฒนา — สิ่งที่ผู้ใช้จริงเห็นคือไฟล์ใน `dist/` เท่านั้น

## กติกาของโปรเจกต์

- ข้อความ UI ทุกข้อความต้องอยู่ใน `src/locales/*.json` และเรียกผ่าน `t('key')` — `npm run lint` จะจับให้
- เนื้อหาบทเรียน (ประโยคอังกฤษ, คำแปลไทย, คำอ่านไทย) อยู่ใน `src/data/` และไม่เปลี่ยนตามภาษา UI
- Stage 1–3 ห้ามแสดงตัวอักษรภาษาอังกฤษ
- วันที่ใช้รูปแบบ `YYYY-MM-DD` ตามเวลาเครื่อง (ไม่ใช้ UTC)
- หน้า `/dev` มีเฉพาะตอน `npm run dev` ไว้ปลดล็อก/ล้างข้อมูลระหว่างทดสอบ
- ข้อความที่ใช้เฉพาะเครื่องมือนักพัฒนา ใส่ใน `src/locales/dev.th.json` / `dev.en.json` (ไม่ใช่ไฟล์ภาษาหลัก)
- ห้ามเก็บของลับ (key, รหัสผ่าน) ไว้ในโค้ดฝั่งเว็บ — ทุกอย่างในเบราว์เซอร์มองเห็นได้ด้วย F12
